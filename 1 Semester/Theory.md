# HTML

`<!DOCTYPE html>` - версия

`<html>` - корень всего документа

`<html lang="ru">` - основной язык сайта

Теги могут быть парными:

```HTML
<html>
    <body> <!--Дочерний <html>, Родитель <nav>-->
        <nav>Текст</nav>
    </body>
</html>
```

`<head>` - служеюная информация о странице (метатеги, кодировки, название страницы, подключение к сторониим файлам (CSS)). Она не отображается на сайте (не относится к контенту)

`<title>Name</title>` - название вкладки/страницы в браузере

`<body>` - видимое содержимое страницы, относится к контенту

## ВАЖНЫЕ семантические парные теги

Семантика - это логика

### ГЛАВНЫЕ КОНТЕЙНЕРЫ (появляются 1 раз)

`<HEADER>` - Блок "Шапка сайта". Секция для вводной информации сайта или группы навигационных ссылок. Может содержать один или несколько заголовков, логотип, информацию об авторе

`<MAIN>` - Блок "Тело сайта". Контейнер для основного уникального содержимого документа. На одной странице должно быть не более одного элемента

`<FOOTER>` - Блок "Подвал сайта". Определяет завершающую область (нижний колонтитул) документа или раздела

Семантика структуры страницы важна для поисковых роботов.

### ВТОРОСТЕПЕННЫЕ КОНТЕЙНЕРЫ (могут повторятся)

#### БЛОЧНЫЕ ЭЛЕМЕНТЫ
ПРАВИЛА БЛОЧНЫХ ЭЛЕМЕНТОВ:
1. Блочные элементы выстраиваются друг за другом по вертикали (по умолчанию). Занимают всю возможную ширину экрана (зависит от его размера)
1. Высота блочных элементов, по умолчанию, автоматически увеличивается от количества и размеров содержимого в них

`<nav>` - Раздел документа, содержащий навигационные ссылки по сайту

---

`<article>` - Раздел контента, который образует независимую часть документа или сайта, например, статья в журнале, запись в блоге, комментарий

`<section>` - Определяет логическую область (раздел) страницы, обычно с заголовком

`<aside>` - Представляет контент страницы, который имеет косвенное отношение к основному контенту страницы/сайта

(Эти 3 используются реже)

---

#### СТРОЧНЫЕ ЭЛЕМЕНТЫ

ПРАВИЛА СТРОЧНЫХ ЭЛЕМЕНТОВ:

1.  Строчные элементы, по умолчанию, занимают столько ширины, сколько нужно для их содержимого, и не начинают новую строку

`<div>` - Элемент-контейнер для разделов HTML-документа. Используется для группировки блочных элементов с целью форматирования стилями. Он универсаленб можно использовать для много чего



##### ИЗОБРАЖЕНИЯ

`<img>` - Встраивает изображения в HTML-документ с помощью атрибута src, значением которого является адрес встраиваемого изображения. Можно вставить ссылку или локальный файл

##### ПЕРЕНОСЫ

`<br>` - Перенос текста на новую строку

##### ЗАГОЛОВКИ И ТЕКСТ

`<h1>-<h6>` - Создают заголовки шести уровней
(H1 - должен быть один на странице)

`<strong>` - Делает обернутый текст жирным

`<em>` - Делает обернутый текст курсивным

`<small>` - Отображает обернутый текст меньшим размером

`<mark>` - Выделяет текст желтым фоном

`<span>` - Можно использовать для форматирования отрывков текста, выделения цветом отдельных слов

## Формы

```html
<form action="./scripts/scriptform.js" method="post">
    <div>
        <label for="login">Логин</label>
        <input name="login" type="email" placeholder="example@mail.ru" required>
    </div>
    <div>
        <label for="password">Пароль</label>
        <input name="password" required>
    </div>
    <button type="submit">Отправить</button>
 </form>
```

`<form>` - Форма для сбора и отправки на сервер информации от пользователей. Не работает без атрибута `action`

`label` - Добавляет текстовую метку для элемента `<input>`

`<input>`- Создает многофункциональные поля формы, в которые пользователь может вводить данные

`<textrea>Большое поле для ввода</textrea>` - Когда нужно больше 255 символов

`<button>` - Создает интерактивную кнопку. Элемент может содержать текст или изображение. Зачастую служит триггером функции

Атрибуты `<input>`:
```html
<input type="text">
<input type="email">
<input type="password">
<input type="number" min="0" step="1">
<input type="date">
<input type="checkbox">
<input type="radio">
<input type="file">
```

Открывающийся список:
```html
<select>
    <option>DivanBoss</option>
    <option>DimanBoss</option>

```

`<select>` - Элемент управления, позволяющий выбирать значения из предложенного множества. Варианты значений помещаются в `<option>`

`<option>`- Определяет вариант/опцию для выбора в раскрывающемся списке `<select>`, `<optgroup>` или `<datalist>`

# Атрибуты тегов

<u>**HTML-атрибуты**</u> это специальные слова, которые управляют поведением HTML-элемента. Они добавляют дополнительную функциональность, либо меняют поведение элемента по умолчанию. Атрибуты элемента выражаются внутри начального тега элемента

Атрибут имеет имя и значение. Имена атрибутов должны состоять из одного или нескольких символов, кроме управляющих, таких как пробел, ", ', >, / и =. Имена и значения атрибутов не чувствительны к регистру, но, тем не менее, рекомендуется набирать их в нижнем регистре

`class` - CSS-класс, который позволяет идентифицировать элемент, задать свойства конкретному элементу или ряду элементов с таким-же названеим

`id` - та-же суть, что и у class, позволяет идентифицировать элемент. Чаще всего применяется для привязки с JS-скрипту

`href` - указывает на адрес ссылки (внешний или внутренний), чаще всего применяется к тегу `<a>`

`src` - путь к файлу изображения (внешний или внутренний), чаще всего применяется к тегам `<script>` и `<image>`

`alt` - текстовое описание изображения. Применяется для тега `<img>`. Необходим для поисковых систем

`title` - дополнительная всплывающая подсказка

`name` - имя поля при отправке формы. Применяется для `<input>`

`value` - позволяет получить значение поля `<input>`

`type` - тип кнопки или поля ввода

`placeholder` - подсказка внутри поля

`required` - проверка заполненности поля ввода `<input>`

`disabled` - отключенный элемент

`checked` - выбранные checkbox/radiobutton

...

# Каскадные таблицы стилей (CSS)

<u>**CSS (Cascading Style Sheets)**</u> — язык таблиц стилей, который позволяет прикреплять стиль (например, шрифты и цвет) к структурированным документам (например, документам HTML и приложениям XML).

Обычно CSS-стили используются для создания и изменения стиля элементов веб-страниц и пользовательских интерфейсов, написанных на языках HTML и XHTML, но также могут быть применены к любому виду XML-документа, в том числе XML, SVG и XUL

Пример:

```
селектор {
    свойтсво: значение;
    свойтсво: значение;
}
```

## Подключение файла стилей к документу .html:
```html
<link rel="stylesheet" hred="./file.css>
```

`<link>` - Позволяет подкоючить файл CSS к файлу .html; рекомендуется подключать в конце тега `<head>`

## Селекторы CSS

Глобальный селектор (применяет свойства ко всем найденным элементам в структуре .html документа)
```CSS
div {
    font-family: Cambria, Cochin, Georgia, Times, 'Times New Roman', serif;
    color: green;
} /* принцип OOP */
```

Селектор класса
```CSS
.myClass {
    color: red;
}
```

Селектор ID
```CSS
#myID {
    color: red;
}
```

Вложенный селектор:
```CSS
ul li {
    font-size: 30px;
}
```
